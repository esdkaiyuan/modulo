# 全项目功能验收设计

## 目标

在不改变账户存储格式和现有视觉设计的前提下，完成全项目自动化回归、注册/登录页面专项验收和真实浏览器渲染检查，修复阻断功能验证的问题。

## 范围

- 运行并修复完整 Vitest 测试套件。
- 保持 `dms-users` 与 `dms-session` 兼容，确保已有本地账户继续登录。
- 验证注册页用户名、邮箱、验证码、密码和确认密码提示的中英文状态。
- 验证登录错误、注册错误、验证码发送状态及倒计时提示。
- 验证认证页七种工具演示能够自动轮播、手动切换并在卸载时停止计时器。
- 在真实 Chromium 浏览器中检查认证页桌面和移动布局、Canvas 动画及控制台错误。
- 运行生产构建，确认发布产物可生成。

## 修复策略

1. 补齐 jsdom 缺失的 Canvas、IntersectionObserver 和 matchMedia 测试替身，让页面测试覆盖真实组件路径。
2. 更新受登录保护影响的旧页面测试，使其显式建立已登录会话，而不是绕过路由保护。
3. 对真实生命周期缺陷做最小修复，包括同步更新退出身份和清理字体 Store 的延迟任务。
4. 对浮点音频结果使用容差断言，不改变正确的 Float32 处理结果。
5. 新增认证页面专项测试，覆盖字段提示、动画轮播、手动切换和登录/注册反馈。

## 验收标准

- `npm test -- --run` 全部通过且没有未处理异常。
- `npm run build` 成功。
- 认证页桌面和移动截图布局完整。
- 浏览器控制台没有未捕获异常。
- 已有账户存储键和数据结构保持不变。

## 非目标

- 不重做认证页面视觉设计。
- 不迁移纯前端账户体系到服务器数据库。
- 不改变邮箱验证码服务协议或 API Key。
- 不处理与本次验收无关的数据隔离架构重构。
